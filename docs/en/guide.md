# Guide

1. Search the [catalog](../index.md?lang=en) by name, ID, model, specification or location. Multiple keywords must all match.
2. Filter by type, operating wavelength, minimum transmission, location or availability.
3. Open Details to check specifications, quantities, location and verification date.
4. Ask the owner to update the inventory after use, return, relocation or damage.

| Quantity | Meaning |
|---|---|
| Available | Ready to use |
| In use | Installed or currently used |
| On loan | Not yet returned |
| Unavailable | Awaiting inspection or damaged |
| Total | Sum of these four quantities |

Wavelength filtering includes both ends of the recorded operating range. Unknown specifications do not match numeric filters. Split ratios use **R:T (reflection:transmission)**. Check wavelength, incidence angle and polarization conditions in the datasheet.

The page shows the latest published snapshot. Demo records are fictional. Copy the page URL to keep the current filters; export includes all matching records.

For updates, see [Maintenance](data-guide.md).
