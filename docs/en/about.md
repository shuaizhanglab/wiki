# About

A lab catalog for finding optical components by type, specification, quantity and location.

Data comes from `inventory.csv` and is built with MkDocs. Included demo records are fictional. Replace them with verified stock and check the physical item and datasheet before use.

The layout references the navigation, content and table structure of [MediaWiki](https://www.mediawiki.org/wiki/MediaWiki) and [Read the Docs](https://docs.readthedocs.com/platform/stable/).
