# 使用

1. 在[目录](index.md)搜索名称、编号、型号、参数或位置。多个关键词同时匹配。
2. 按类型、工作波长、最低透过率、位置或“仅看可用”筛选。
3. 打开“详情”，核对参数、数量、位置和盘点日期。
4. 取用、归还、转移或发现损坏后，通知负责人更新台账。

| 数量 | 含义 |
|---|---|
| 可用 | 可以取用 |
| 在用 | 已装入装置或正在使用 |
| 借出 | 尚未归还 |
| 待检 / 损坏 | 暂不能取用 |
| 总量 | 上述四项之和 |

工作波长筛选按已记录的适用区间匹配，包含边界。未知参数不满足数值筛选。分光比按 **R:T（反射:透射）** 记录；光学参数应结合规格书中的波长、入射角和偏振条件核对。

页面显示最近一次发布的库存。示例记录不代表实际库存。复制页面地址可保留筛选条件；导出包含全部匹配记录。

维护人员见[维护](data-guide.md)。
